#Wazuh SIEM – Cybersecurity Homelab

#Project Overview

This project focuses on building a Security Information and Event Management (SIEM) environment using Wazuh.

The goal is to gain practical experience in security monitoring, log analysis, threat detection, and incident investigation.


#Objectives

Deploy and configure a working Wazuh SIEM.

Connect Linux endpoints using Wazuh agents.

Collect and analyze security logs.

Detect suspicious SSH authentication activity.

Investigate security alerts.

Document detection scenarios and findings.
